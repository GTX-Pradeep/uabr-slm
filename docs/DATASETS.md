## The controlled facts (not downloaded)

The invented people and their facts are generated by `src/data/build_facts_v2.py` with fixed random seeds; no language
model is used to create any data. Names are built from syllables so they cannot appear in Wikipedia, and each fact's
answer is a real Wikidata value. This is what makes the experiment measurable: the exposure ledger records exactly how
many times the model saw each fact (0, 40, 120 or 300). Running `notebooks/phase2v2_build_data.ipynb` rebuilds the same
data bit for bit. Splits are by person (50 / 20 / 10 / 20%), and test question templates never appear in pretraining.
